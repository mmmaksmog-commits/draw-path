# ✏️ Нарисуй путь

**Физическая головоломка: рисуйте линии пальцем — шарик покатится по ним.**

### ▶️ [Играть](https://mysik-portfolio.vercel.app/draw-path/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Собственный физический движок: гравитация, отскоки, трение
- Столкновение круга с отрезками с подшагами для стабильности
- 5 уровней, звёзды и ограничение чернил
- Рисование мышью и пальцем, отмена линии

## Стек

Canvas 2D, своя физика. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/draw-path.git
cd draw-path
python3 -m http.server 8000
```
